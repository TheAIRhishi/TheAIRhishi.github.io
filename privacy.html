Privacy Policy

Last updated: 2026-10-27

This policy covers the website theairhishi.github.io and the private posting tool "AI Rishi Postiz" that Aayush Sharma Niroula uses to publish to his own social media accounts (Facebook Page, Threads, TikTok, Bluesky, YouTube and others).

Who uses the tool

Only Aayush Sharma Niroula. The tool is not offered to the public, and no other person can sign in to it.

What information the tool handles

  • Sign-in permissions (access tokens) for Aayush's own accounts, granted by him through each platform's official login screen.
  • Basic details of those accounts that the platforms return, such as the account or Page name, ID and profile picture.
  • The posts, images and videos Aayush creates and publishes.

The tool does not collect, buy or sell information about other people. It does not read private messages. It may read public engagement numbers (likes, comments, views) on Aayush's own posts.

Where it is stored

On Aayush's own computer, in a self-hosted copy of the open-source tool Postiz. It is not shared with anyone else, except the platforms themselves when a post is published.

This website

This site is a static site hosted by GitHub Pages. It has no sign-up, comments, forms, cookies or analytics. GitHub may keep standard server logs; see GitHub's privacy statement.

Deleting data

Aayush can remove the tool's access at any time from each platform's settings (for Facebook: Settings > Apps and Websites). He then deletes the stored tokens and account details from the tool. If you believe the tool holds information about you, email asblogger53@gmail.com and it will be deleted within 30 days.

Changes

Updates to this policy appear on this page with a new date.
